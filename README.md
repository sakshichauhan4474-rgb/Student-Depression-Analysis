# Student Depression Analysis using SQL & Tableau

A complete Data Analytics project focused on student depression trends and behavioral analysis using Microsoft SQL Server and Tableau.

The project includes data cleaning, preprocessing, SQL-based exploratory analysis, and interactive dashboard development to identify how factors such as academic pressure, sleep duration, dietary habits, study hours, and financial stress influence student depression.

The dashboard provides data-driven insights that help understand mental health patterns among students through dynamic visualizations and KPI reporting.

## Skills Used

* SQL Queries
* Data Cleaning
* Data Transformation
* Exploratory Data Analysis (EDA)
* Data Visualization
* Dashboard Design
* Analytical Thinking
